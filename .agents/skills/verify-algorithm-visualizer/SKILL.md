# 算法可视化验收

读取 [references/verification-matrix.md](references/verification-matrix.md)，按改动风险选择测试范围。发现失败时先修复再复测，不把明显问题留给用户验证。

## 验收顺序

1. 运行静态检查或构建检查，确保无语法和资源错误。
2. 用独立参考结果验证算法输出和统计。
3. 验证步骤序列、代码行、变量和解释语义一致。
4. 遍历播放状态：开始、播放、暂停、前进、回退、调速、结束、重播、重置。
5. 验证默认、边界、非法和随机输入。
6. 在桌面、平板和移动视口检查画布非空、文本不重叠、控件可用。
7. 回归至少一个未修改模块；共享引擎变更时回归全部模块。

## 证据要求

报告实际执行的命令、覆盖的输入和视口、失败及修复结果。视觉功能优先保留截图或浏览器检查证据。无法执行某项测试时明确说明原因和残余风险。

## 阻断问题

- 排序/搜索结果错误或统计伪造
- 回退后状态与对应快照不一致
- 代码高亮与解释指向不同动作
- 播放结束后定时器继续改变状态
- 非法输入导致崩溃或无反馈
- 主要控件在 390px 宽度不可见或重叠
- 控制台异常、资源 404 或空白画布

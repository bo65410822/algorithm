# 验证矩阵

## 算法层

- 输出与可信参考实现一致
- 输入不被非预期修改
- 比较、交换、访问等统计定义一致
- 最好、平均、最坏情况说明准确
- 重复值和边界输入行为明确

## 步骤层

- 步骤 ID 严格递增
- 每个代码行号存在
- 任意游标的快照可独立渲染
- 从头重放与直接读取最终快照一致
- 前进一步再后退一步恢复完全相同状态

## 交互层

| 场景 | 预期 |
| --- | --- |
| 初始 | 第 0 步、无定时器、控件状态正确 |
| 播放 | 按当前速度递增且不跳步 |
| 暂停 | 游标停止变化 |
| 手动单步 | 自动暂停并精确移动一步 |
| 末尾 | 停止播放、显示完成解释 |
| 重新播放 | 从第 0 步重新开始 |
| 新输入 | 旧定时器清除、步骤与统计重建 |

## 输入层

- 空输入、分隔符异常、非数字、小数
- 少于最小数量、超过最大数量
- 最小值、最大值、重复值
- 已有序、逆序、全部相等

## 视觉层

检查 1440x1000、768x1024、390x844。确认画布有内容，标题和按钮无截断，代码可读，解释不覆盖统计，固定控件不产生布局跳动，深浅主题均有足够对比度。

## 回归策略

- 模块内部改动：本模块全量 + 冒泡排序冒烟。
- 共享渲染器改动：所有使用该渲染器的模块。
- 引擎或步骤契约改动：全部模块的播放状态机和最终结果。
- 页面外壳改动：全部目标视口和主题。

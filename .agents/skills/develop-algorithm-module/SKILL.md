# 算法模块开发

开始前阅读 [references/module-checklist.md](references/module-checklist.md)。若新增模块要求改变共享协议，同时使用 `$design-algorithm-visualizer`。

## 实现顺序

1. 写清教学目标和本模块必须回答的一个核心问题。
2. 确定合法输入范围、默认案例、边界案例与复杂度。
3. 编写正确且适合教学的 Java 过程代码；代码行号必须能与步骤对应。
4. 让过程代码等价逻辑生成结构化步骤，不直接操作页面。
5. 为每种步骤生成完整状态和一句具体中文解释。
6. 接入通用播放控制、变量区、统计区和模块注册表。
7. 验证自定义输入、重复值、有序/逆序输入、单步、回退、自动播放和重置。

## 开发约束

- 不复制播放器、速度控制、代码高亮或输入错误处理。
- 不把动画帧当算法步骤；一个步骤表达一个可解释的语义动作。
- 解释必须引用当前值、索引、节点或边，避免“正在执行当前操作”这类空话。
- 算法结果、统计和完成条件来自模块逻辑，不从 DOM 推断。
- 输入错误要在原位置提示，不得静默修正为不同含义的数据。
- Java 代码与 JavaScript 步骤生成逻辑必须语义一致。
- 保持中文界面，标识符和代码使用英文。

## 完成定义

模块能够从选择入口打开，默认输入可完整播放，自定义输入会重新生成步骤，任意步骤可前进和回退，代码行与解释同步，完成状态和复杂度准确，现有模块无回归。

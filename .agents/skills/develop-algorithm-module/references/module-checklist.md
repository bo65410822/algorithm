# 模块开发清单

## 模块定义

- 唯一 `id`、中文标题、分类、难度、预计时间
- 一句话教学目标和一个理解检测问题
- 默认输入、输入限制、解析错误文案
- Java 示例代码和稳定行号
- 时间、空间复杂度及其适用条件

## 步骤设计

根据算法选择语义事件，例如：

- 排序：`compare`、`swap`、`write`、`markSorted`
- 搜索：`probe`、`discardRange`、`found`、`notFound`
- 链表：`visitNode`、`updateNext`、`insertNode`、`removeNode`
- 树和图：`visit`、`enqueue`、`dequeue`、`relaxEdge`、`markDone`

每个步骤必须包含唯一序号、类型、代码行和语义载荷。需要动画的状态变化保留前后快照。

## 边界案例

- 最小合法输入
- 已完成或已排序输入
- 逆序或最坏情况
- 重复值
- 目标不存在（搜索类）
- 非法、空、过长和超范围输入

## 教学解释

每句解释回答至少一个问题：比较谁、为何改变、排除了什么、哪个不变量成立、下一步范围如何变化。完成解释包含结果和关键统计，不只写“执行完成”。

## 禁止模式

- 在事件处理器里重新实现算法
- 用元素颜色判断算法状态
- 为每个算法复制一套播放按钮
- 通过延时嵌套控制正确性
- Java 展示代码与实际过程不一致
- 为演示效果伪造比较或交换次数

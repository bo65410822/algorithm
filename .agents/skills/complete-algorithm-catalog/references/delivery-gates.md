# 交付门槛

## 每个模块必须通过

1. **注册**：唯一 ID、分类、难度、预计时间、默认输入和状态存在。
2. **正确性**：默认、最小、典型、重复/特殊、最坏和非法输入符合参考结果。
3. **过程**：步骤顺序、Java 代码行、变量、解释、完成条件和统计语义一致。
4. **状态机**：播放、暂停、前进、回退、重置、调速、结束重播和替换输入确定可用。
5. **教学**：至少一个明确教学目标、逐步解释和理解检测；解释引用当前实际数据。
6. **视觉**：1440x1000、768x1024、390x844 下画布非空，文字和控件不重叠。
7. **无障碍**：键盘可操作、图标有名称、状态不只依靠颜色、减少动画偏好可用。
8. **回归**：冒泡排序和所有共享层受影响模块通过。
9. **运行质量**：无语法错误、控制台异常、资源 404 和残留定时器。

任何一项失败，状态保持 `implementing`。

## 验证证据

为自动测试保留命令输出；为视觉检查保留临时截图并在检查后清理。验收记录至少包含模块 ID、测试输入、视口和通过时间。不要把验证证据硬编码成永远通过的静态文本。

## 最终目录必须通过

- 14 个注册表条目全部为 `complete`，且没有重复 ID 或失效路由。
- 总览数量、分类和状态与注册表一致。
- 每个模块能从总览进入，也能通过直接 URL 打开。
- 所有模块共享同一播放器，不存在复制的控制状态机。
- 全部自动测试一次性通过。
- 三个目标视口下依次打开所有模块，无空白画布、遮挡和页面横向溢出。
- 深浅主题和演示模式不会破坏关键操作。
- 冒泡排序原始教学目标与功能保持可用。

只有以上条件同时满足，完整目录才算完成。

# 教学交互设计

读取 [references/interaction-guidelines.md](references/interaction-guidelines.md)，以理解效果而非装饰性动画作为判断标准。

## 核心流程

1. 让用户先看到当前问题、输入和可执行画布。
2. 同步呈现算法状态、对应代码行、关键变量和一句解释。
3. 提供播放、暂停、前进、回退、重置和速度控制。
4. 在关键节点鼓励用户预测，再揭示下一步。
5. 完成后展示结果、统计、复杂度和一个理解检测。

## 强制约束

- 相同语义在所有模块中使用一致颜色和控件位置。
- 颜色不能是唯一状态线索；同时使用标签、形状、指针或文字。
- 动画时长服从速度设置，并尊重 `prefers-reduced-motion`。
- 单步操作立即产生确定结果，不被尚未结束的动画锁死。
- 桌面端优先并列展示代码与画布；移动端优先画布和控制，再展示代码。
- 紧凑工具界面不使用营销式大标题、装饰卡片或无关视觉效果。
- 图、树、数组等固定格式画布必须有稳定尺寸，动态内容不得推动控制区跳动。
- 所有图标按钮提供可访问名称或 tooltip，键盘焦点清晰。

## 文案规则

解释具体说明当前值、位置、原因和结果。术语首次出现可简短定义，但不要在界面堆使用说明。错误反馈放在操作附近，并告诉用户如何修正。

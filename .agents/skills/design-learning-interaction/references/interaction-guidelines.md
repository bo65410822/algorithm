# 教学交互规范

## 信息优先级

1. 当前算法状态和正在发生的动作
2. 对应 Java 代码行和变量
3. 当前步骤原因
4. 进度、统计和复杂度
5. 理解检测与后续内容

## 状态词汇

| 状态 | 建议表达 |
| --- | --- |
| 当前访问 | 高亮边框、指针和标签 |
| 正在比较 | 琥珀色 + “比较”标签 |
| 正在修改 | 红色过渡 + 动作说明 |
| 已完成 | 绿色 + “已就位/已访问”标签 |
| 已排除 | 降低对比度 + 范围说明 |

不同算法可以增加状态，但不得改变共享状态的既有含义。

## 播放行为

- 播放到末尾后按钮恢复为播放；再次播放从头开始。
- 手动前进或回退自动暂停。
- 重置回到第 0 步并恢复默认状态，不改变当前输入。
- 应用新输入后重新生成全部步骤并回到第 0 步。
- 播放中调整速度应立即生效。

## 响应式

- 1440px：代码与画布同时进入主要视区。
- 768px：允许上下布局，控制区不能溢出。
- 390px：画布、解释和主要播放按钮优先；次要统计可换行。
- 最长中文文案、两位数数组值和 8 个元素不得相互覆盖。

## 无障碍

- 控件使用真实 `button`、`input` 和 `label`。
- 状态不只依赖颜色。
- 保持合理对比度和可见焦点。
- 动态解释可使用温和的 `aria-live="polite"`，避免每帧播报。

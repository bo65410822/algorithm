# AlgoLab

Java 数据结构与算法可视化教学工具。通过同步的 Java 示例代码、算法状态、关键变量和中文解释，逐步理解算法执行过程。

## 已实现模块

- 排序：冒泡、选择、插入、归并、快速排序
- 查找：线性查找、二分查找
- 线性结构：栈、队列、单链表
- 树：二叉搜索树、二叉堆
- 图：广度优先搜索、深度优先搜索

## 本地运行

项目是无构建依赖的静态 Web 应用。进入项目目录后启动静态服务器：

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

访问 <http://127.0.0.1:5173>。

## 测试

```powershell
npm test
```

测试覆盖 14 个模块的注册信息、步骤协议、算法正确性、输入边界和播放器状态。
